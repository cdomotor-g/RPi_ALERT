Location

Where the receivers are. Anything but a GPS fix is recorded in MegaNet as approximate.

RTL-SDR

Every RTL-SDR stick plugged in listens on this channel. ALERT Binary is what the 151.5 MHz networks send; Enhanced iFLOWS is what an ERT-A2 set to it sends. One format at a time, on purpose.

Serial devices

Quansheng radios, ERT-A2 receivers and GPS units are recognised from what they send. Set a port's type here only if it is not.

Audio
